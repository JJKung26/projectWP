สิ่งที่ต้องมี: Windows 64-bit และ Node.js 24 x64

วิธีรันแบบที่ 1
1. แตก ZIP แล้วเข้าโฟลเดอร์ที่มี START.bat และ package.json
2. ดับเบิลคลิก START.bat หรือเปิด PowerShell ในโฟลเดอร์นี้แล้วพิมพ์คำสั่งเดียว:
   .\START.bat
3. เปิดลิงก์ Local ที่แสดงในหน้าต่างเพื่อเข้าสู่ระบบ

โปรแกรมจะติดตั้งแพ็กเกจที่ขาด ดาวน์โหลด Cloudflare ถ้ายังไม่มี และเตรียมฐานข้อมูลให้เอง
เปิดหน้าต่างนี้ไว้ระหว่างใช้งาน

วิธีรันแบบที่ 2
npm.cmd ci
npm.cmd start

ใช้ npm.cmd ci เพื่อติดตั้งแพ็กเกจครั้งแรก ครั้งถัดไปใช้แค่ npm.cmd start
